# ADR 0017：检索返回完整摘要并支持多页，缺的摘要从 PubMed 补

- 状态：Accepted
- 实施情况：已实现。单元测试覆盖游标翻页、摘要不截断、各摘要来源和 PubMed 失败时的表现；线上验证见「验证要点」。

## 背景

一次 agent 会话要筛出 Cell、Nature、Science 四个月内的文章，暴露出检索和元数据的三处不足：

1. `search` 的摘要截在 500 个字符。agent 不敢用截断的摘要做判断，改去 PubMed 和出版社网页逐篇补，三个子任务共补了约 60 篇。
2. `metadata` 只查 Crossref，而 Nature 等出版商不向 Crossref 提交摘要，结果里没有摘要。
3. 一次最多 100 条，不能翻页。agent 只好把四个月拆成十几个日期窗口，一个窗口超过 100 条还要再拆。

同一会话还发现 OpenAlex 数据的两个特点：Cell 等期刊的 `publication_date` 只到月，一律记为当月 1 日，从某月 2 日开始的窗口会漏掉整个月；新闻、社论常被标成 `article`。

## 决策

1. `search` 返回完整摘要，不再截断。
2. `limit` 上限从 100 提高到 1000。不超过 100 时仍只取一页；更大时用 OpenAlex 的游标每页取 100 条，取到候选比 `limit` 多出约 10 条（留给本地过滤掉的条目）或没有下一页为止。返回格式仍是 JSON 数组。
3. `metadata` 按 DOI 查询时，结果增加 `journal` 和 `abstract`。摘要依次取 Crossref（去掉 JATS 标签）、OpenAlex、PubMed，用第一个有的。
4. `search` 的结果里 OpenAlex 没有摘要的，按 DOI 批量查 PubMed 补上：每 100 个 DOI 一次检索加一次取回。PubMed 分段的摘要保留段名，如 `BACKGROUND: …`。
5. 补摘要的请求失败时，那几篇只是没有摘要，检索结果和 `metadata_status` 不受影响。
6. OpenAlex 数据的两个特点写进 README 和 agent skill，代码不做处理。

## 理由与替代方案

- **摘要加开关，默认仍截断**：完整摘要每条约 1–2 KB，100 条约 150 KB，1000 条约 1.5 MB，写到文件里处理没有问题。截断的摘要实际上没人用，加开关只是多一个要记住的参数。
- **摘要只用 OpenAlex**：OpenAlex 缺很多出版商的摘要。实测 Cell 7–11 月 230 条里有 101 条没有，Nature 9–10 月 230 篇研究论文里有 81 篇没有；PubMed 分别补回 93 和 80 篇，每批约 6 s。PubMed 只收生物医学，其他领域的论文补不到。
- **返回游标让调用方自己翻页**：要改返回格式，agent 还得写循环。按 `limit` 自动翻页对现有调用方完全兼容。
- **上限定为 1000**：一本主刊几个月的全部条目通常在这个量级以内。OpenAlex 的检索请求按次计费，1000 条是 10 次请求，在每日免费额度内。
- **按 OpenAlex 的入库日期筛选来绕开日期精度问题**：入库日期和上线日期并不一致，用它代替发表日期会带来另一种误差，所以只提醒调用方按整月划分窗口。

## 后果

- 大 `limit` 的检索变慢，每多一页约多一次 OpenAlex 请求的时间，并消耗相应额度。
- 检索结果 JSON 明显变大。
- 有论文缺摘要时，检索多两次 PubMed 请求，约多几秒；`metadata` 在 Crossref 没有摘要时多一到三次请求。

## 验证要点

已验证：

- 单元测试：`limit` 超过 100 时依次带上 `*` 和返回的游标，够数或没有下一页时停止；摘要不截断；`metadata` 的摘要分别取自 Crossref（去掉标签和 Abstract 标题）、OpenAlex 和 PubMed；PubMed 按 DOI 匹配、保留段名、每 100 个一批，请求失败时返回空。
- 线上（PubMed 补摘要之前）：按 Cell 的 ISSN 检索 2026-07-01 至 2026-11-30，`--limit 1000` 一次拿到 230 条，没有重复；最长的摘要约 1400 字符。`asource metadata --doi 10.1016/j.cell.2026.08.053` 返回完整摘要。

部署后验证：

- 同一 Cell 检索和 Nature 9–10 月检索，缺摘要的条目大多由 PubMed 补上；`asource metadata --doi 10.1038/s41586-026-11300-1` 返回摘要。
