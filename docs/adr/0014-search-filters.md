# ADR 0014：搜索提供常用筛选参数和原样转发的 OpenAlex filter

- 状态：Accepted
- 实施情况：已实现。命令行、HTTP、MCP 和 Python 客户端使用同一组参数；单元测试覆盖参数换算、期刊名解析、默认排除规则和错误传递。帮助里的示例都对 OpenAlex 实际跑过。

## 背景

搜索原来只有关键词和条数两个参数。底层的 OpenAlex 封装还支持年份、排序和作者，但没有对外开放；给了作者时，关键词会被丢掉。非论文类型和撤稿论文在取回结果后才在本地剔除，所以返回的条数常常不够。结果里也没有期刊名。

用户需要按期刊等条件筛选。搜索只走 OpenAlex，它的 works 接口有大约 150 个 filter 字段，以及一套组合语法：逗号表示 AND，同一字段内用 `|` 表示 OR，`!` 表示取反，`>`、`<` 用于比较数字。

## 决策

1. **常用条件做成参数**，彼此之间是 AND，四个入口的名字相同：
   - `journal`：ISSN，或者期刊的准确名称；
   - `year`：`2021`、`2020-2024`、`2020-` 或 `-2024`；
   - `type`：逗号分隔的 OpenAlex 类型，满足其中一个即可；
   - `oa`：只要开放获取的论文；
   - `min_citations`：被引次数至少为 N；
   - `author`：作者名、OpenAlex 作者 ID 或 ORCID，现在可以和关键词一起用；
   - `sort`：`cited_by_count` 或 `publication_date`，可加 `:asc` 或 `:desc`；
   - `in`：关键词的匹配范围。`all` 匹配标题、摘要和全文，是默认值；`title` 只匹配标题；`abstract` 匹配标题或摘要。
2. **`filter` 参数原样转发**给 OpenAlex 的 `filter`，和上面的条件用逗号连接。只转发这一个参数；`per_page`、`select`、`api_key` 等不开放，以免改变结果格式和计费。我们不检查它的语法，OpenAlex 拒绝时把它的错误说明原样交给调用方：HTTP 400、MCP 工具错误、命令行非零退出。
3. **期刊名的解析**：在 OpenAlex 的期刊列表里搜索这个名字，只看按相关度排序的第一页（100 条）。先找名称完全相同的期刊，再看别名和缩写；只有一本相符时按它的 ID 筛选。有歧义或找不到时报错，并列出最多 10 个候选的名称和 ISSN-L，调用方改用 ISSN 重试。
4. **默认排除非论文和撤稿**，并把排除条件发给 OpenAlex，不再只在本地剔除，这样返回的条数是满的。调用方用参数或 `filter` 指定了 `type` 时，不再排除任何类型；`filter` 里出现 `is_retracted` 时，不再排除撤稿论文。本地的剔除规则保留，用来兜住 OpenAlex filter 不认识的旧类型标签。
5. **没有关键词时默认按出版日期从新到旧排序**，有关键词时按相关度。待确认：这是替用户选的默认值，理由是只用筛选条件时，最常见的需求是看最新的论文。
6. 结果增加 `journal` 字段（期刊或来源的名称）。

## 理由与替代方案

- **只提供原样转发**：灵活，但每次都要写 OpenAlex 语法，常见需求的门槛太高。
- **只提供参数**：OpenAlex 的字段太多，挑出来的参数总会漏掉某些需求，比如国家、语言、资助方。
- **期刊名翻遍所有结果页来确认唯一**：搜 "Nature" 有 303 个部分匹配，要翻 4 页，每页都按搜索计费；准确名称一般排在第一页。
- **只按别名判断**：Developmental Cell 的别名里有 "Cell"，只按别名会让最常用的 Cell 变成有歧义，所以期刊本名优先。
- 实测（2026-11-20）：OpenAlex 不接受 `type:!a+!b` 这种写法（HTTP 400），接受重复的 `type:!a,type:!b`；按 ORCID 筛选时，`author.orcid` 和 `authorships.author.orcid` 结果相同；每个示例请求 0.8–2.6 s。

## 后果

- `filter` 让 OpenAlex 的 filter 语法成了我们对外契约的一部分。OpenAlex 改语法时，用户写的表达式可能失效；搜索本来就只依赖 OpenAlex，这个风险可以接受。
- 带关键词的请求和期刊名解析按搜索计费，每千次 1 美元；纯筛选请求每千次 0.1 美元。
- OpenAlex 给的期刊名和类型并不总是准确，筛选结果也继承这些误差。

## 验证要点

已验证：

- 单元测试：参数到 filter 的换算、年份格式、期刊名解析（本名优先、歧义、无匹配）、指定类型后不再排除、OpenAlex 400 的错误说明传给四个入口。
- 对 OpenAlex 实际执行帮助里的五个示例，以及 `journal=Nature`（解析成功）、`journal=Cell`（解析为 Cell）和一个无效字段（返回 OpenAlex 的错误说明）。

待验证：

- 部署后通过服务端执行同样的示例。
